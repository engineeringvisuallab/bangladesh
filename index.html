বাস্তব 3D Terrain চালু করুন

Terrain যোগ করতে Cesium ion access token দরকার। Token ছাড়া অ্যাপ চলবে, তবে ভূমির উচ্চতা বাস্তবভাবে ওঠানামা করবে না।

Cesium ion থেকে token নিন ↗

Token এই ব্রাউজার ট্যাবের session storage-এ থাকবে; ট্যাব বন্ধ করলে মুছে যাবে। পাবলিক সাইটে ব্যবহারের জন্য সীমিত permission-সহ token তৈরি করুন।
